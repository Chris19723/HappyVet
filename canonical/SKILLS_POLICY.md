## CANDIDATE DESIGN SKILLS
- DESIGN.md / Awesome DESIGN.md;
- getdesign.md;
- Taste Skill;
- Impeccable;
- Emil Kowalski design/motion skill.

## PRINCIPLES
1. Use the minimum skill set needed.
2. PRODUCT.md outranks visual preference.
3. DESIGN.md is the approved visual source of truth.
4. Security rules outrank any third-party skill.
5. A skill cannot widen filesystem/network/Git permissions.
6. Never claim a skill was executed if it was not.
7. Skills may critique and propose.
8. HQ approves product-level changes.
9. Durable decisions must be written to canonical docs.

## DEFAULT ROUTING

### Product / UX direction

### Anti-generic / visual direction

### Audit / polish / accessibility / responsive
Impeccable.

### Motion / interaction
Emil Kowalski skill.

### Frontend implementation
Claude Code by default.

### Backend / data / security implementation
Codex by default.

### Runtime / preview / visual verification
Replit.

## EXTERNAL SKILL SAFETY
Before installing or executing third-party skills:
- inspect instructions;
- inspect requested permissions;
- reject unnecessary secret access;
- reject destructive Git actions;
- reject arbitrary network calls;
- reject scope expansion.
